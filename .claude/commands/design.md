When working on UI components or design:

1. Fetch latest Base UI docs from https://base-ui.com/llms.txt using WebFetch
2. Use shadcn MCP tools to search components and get examples
3. Follow shadcn best practices and Base UI accessibility patterns
4. Style with Tailwind CSS
5. Make sure the interface is mobile-first design ( app-liked )
6. Use Server-Side Component and Server Action whenever possible
